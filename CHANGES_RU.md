# Исправления по результатам реверс-инжиниринга

## Целостность контейнера

Python и TypeScript теперь проверяют три CRC-16/XMODEM:

| Область исходного файла | Поле | Порядок байтов |
|---|---|---|
| `[0x100,0x8D00)` | `0xB0..0xB1` | big-endian |
| `[0x80,0x8D00)` | `0x11..0x12` | little-endian |
| `[0x8D00,0x1E480)` | `0x1F..0x20` | little-endian |

При изменении параметра сначала пересчитывается внутренняя CRC A, затем внешняя.
Для параметра 35 результат: `23 20` в `0x5C76`, `9D B1` в `0xB0`, `C4 8A`
в `0x11`. Допускается изменение только шести этих байтов. Второй компонент,
KERS, сертификаты и подпись не изменяются.

Результат старого алгоритма с правильной внутренней CRC и устаревшей внешней
теперь отклоняется. `crc_valid` означает совпадение всех трёх CRC, а в manifest
добавлены отдельные статусы, вычисленные значения, интервалы и порядок байтов.

## Криптографическая проверка

Добавлен инструмент `tools/verify_ota.py`. Он проверяет ECDSA/SHA-256/P-256
для `[0,0x1E4C6)` под вложенным leaf-ключом и подпись leaf-сертификата под
вложенным intermediate. Корень доверия и принятие пакета загрузчиком не проверены.

Ядра патчера остаются без зависимости от cryptography: они явно отмечают
`ota_signature_verification: not_performed` и нарушение исходной подписи
изменением подписанных данных. Отдельный инструмент действительно выполняет
криптографическую проверку: исходный OTA проходит, изменённый не проходит.

Для инструмента и полного набора тестов:

```sh
pip install -r requirements.txt -r requirements-re.txt
python tools/verify_ota.py original.bin
```

## Интерфейсы и документация

React и Streamlit показывают проверку всех CRC и статус подписи раздельно.
Кэш Streamlit учитывает версию алгоритма: сохранённый старой версией файл
после обновления больше не предлагается для скачивания.

В спецификацию внесены границы двух образов, базы анализа 0 и `0x08003000`,
источник параметра из принятого сообщения `0x12/0x20`, RAM `0x20000234` и
подтверждённые потребители поля. Соответствие физическим км/ч и поведение
Eco/Drive/Sport не объявлены установленными.

## Проверки этой версии

- 18 Python-тестов, включая Streamlit, оригинальный OTA и ECDSA: проходят.
- 7 TypeScript-тестов с оригинальным OTA: проходят.
- Проверка типов активного приложения и production-сборка: проходят.
- Для параметров 25, 35, 45, 60 совпадают SHA-256 выходных данных и полные
  manifest Python/TypeScript. Все три CRC дополнительно сверены через
  независимый `binascii.crc_hqx`.

Проверки выполнялись в памяти; готовые изменённые прошивки не сохранялись.
Аппаратная запись на самокат не выполнялась. Исправление целостности контейнера
не делает изменённую прошивку подписанной или аппаратно проверенной.
